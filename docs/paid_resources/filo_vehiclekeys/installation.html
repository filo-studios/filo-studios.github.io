Installation

Dependencies, items, controls and commands.

Dependencies

ResourceRequiredUsed for
ox_libYesCallbacks, keybinds, progress bars, notifications
oxmysqlYesKey data storage
community_bridgeYesFramework, inventory and notification bridge
sleepless_promptsYesIn-vehicle and locksmith prompts (included in the download)
eye_minigamesDefaultMinigames when Config.Minigames = 'builtin'

ox_targetOptionalLocksmith interactions when Config.InteractionType = 'target'
ps-dispatchOptionalDispatch when Config.Dispatch.System = 'ps-dispatch'
xsoundOptionalIgnition sounds
filo_blipsOptionalLocksmith blips (falls back to native blips)
baseeventsRecommendedLock state and NPC vehicle locking on entry

Supported frameworks (through community_bridge): Qbox, QBCore and ESX.

filo_textui is no longer used. v2.0.0 uses sleepless_prompts for all prompts.

Setup

Put filo_vehiclekeys (and sleepless_prompts, tr_core, tr_minigames from the download) in your resources folder.
Add the items from INSTALL/ox_inventory.txt to your inventory and copy the images from INSTALL/item images. If you use tr_minigames, also add wire_strippers from tr_minigames/install/ox_inventory/items.lua.

Ensure the resources after their dependencies:

Start the server. The filo_vehiclekeys table is created automatically.
Remove any other vehicle key resource. This one provides qb-vehiclekeys, qbx_vehiclekeys and filo_vehiclekey.

Items

ItemPurpose
vehiclekeyThe key or fob itself (metadata holds plate and key ID)
lockpick / advanced_lockpickLockpicking
electrical_toolsHotwiring and repairing hotwired ignitions
blank_keyConsumed when a locksmith makes a key
key_cutting_toolCutting mechanical keys
locksmith_tabletProgramming fobs over OBD
police_bypassPolice master key (only if Config.PoliceBypass.Item is set)

vehiclekey must have stack = false: each key is a unique item with its own metadata.

Controls

Default keyAction
LLock / unlock the closest vehicle
GInsert / remove the key (hold to start the engine)
MEngine on / off
HHotwire
YSearch the vehicle for keys

Players can rebind these in the FiveM key bindings menu. Defaults are in Config.DefaultKeybinds.

Commands

CommandPermissionDescription
/givekey [id] [plate] (alias /givekeys)group.adminGive a key. Defaults to yourself and your current vehicle. Plates may contain spaces. Works for stored vehicles.
/givejobkey <job> [plate]group.adminGive a job access to a spawned vehicle
/keyadmingroup.adminOpen the admin panel

SQL Table

Created automatically on first boot. Only player-owned vehicles are written, and records inactive for Config.VehicleDataRetentionMonths are pruned.
