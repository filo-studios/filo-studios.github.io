Item-based vehicle keys for FiveM: physical keys and key fobs, ignition handling, lockpicking,
hotwiring, NPC carjacking, a locksmith job, police dispatch and an admin panel. All outcomes are
decided on the server and everything is tuned from `shared/sh-config.lua`.

<Callout type="info">
  Current version: **2.0.0**. Framework, inventory, minigame, dispatch and target code lives in the
  open `bridge/` folder, so you can adapt it to your server.
</Callout>

## Features

**Keys**
- Keys are `vehiclekey` items tied to a plate and a key ID; a new key ID instantly invalidates every old copy
- Mechanical keys and keyless fobs (auto-detected for electric models, or per model)
- Key fob UI: lock, unlock, trunk, panic, remote engine, convertible roof, summon, auto-lock and auto-start
- Insert/remove keys from the ignition, hold to start the engine
- Job keys: give a whole job access to a vehicle without an item
- Keys for unowned vehicles are removed on despawn and after a restart

**Theft**
- Lockpick and advanced lockpick with per-tier success chances, durability and alarm chance
- Hotwiring with per-tier times and minigame difficulty
- Difficulty tiers mapped by GTA vehicle class, with per-model overrides
- Searching parked vehicles for keys
- NPC carjacking: aim at a driver, hold them up, take the car and its key
- Model blacklist per action

**Police**
- Bypass for configured jobs (grade, duty, optional `police_bypass` item)
- Dispatch alerts via ps-dispatch, a built-in notify + blip, or your own function

**Locksmith & Admin**
- Key cutting, OBD fob programming and ignition repair
- NPC store for spare keys when not enough locksmiths are on duty
- `/keyadmin` panel to manage vehicles, key IDs, job access and keys
